First Impressions of Software Engineering Bootcamp

The first weeks were both exciting and overwhelming. I explored modern web fundamentals, learned how to organize my files, and got familiar with Git workflows.

I realized that being consistent with small daily tasks is key to progress, even simple commits and notes on my projects make a huge difference.

Why Clean Semantic HTML is Essential

Using proper HTML5 semantic tags improves accessibility, readability, and maintainability. Tags like <header>, <section>, and <article> give meaning to your content.

Even when just starting, I noticed that semantic HTML:

  • Helps screen readers navigate content efficiently
  • Makes future code changes easier
  • Improves search engine indexing
