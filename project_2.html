    • What Problem Does It Solve?

    Many small businesses struggle to manage customer relationships effectively, especially when relying on basic tools like spreadsheets and manual communication.

    This project aimed to create a simple CRM system that integrates with WhatsApp for communication and supports USSD for easy access, helping businesses keep track of customer interactions and sales.

    My Approach

    I focused on building a user-friendly interface that allows businesses to manage customer data, track interactions, and send messages through WhatsApp.

    The project emphasized:

    • Designing a simple database schema for customer information
    • Integrating with the WhatsApp Business API for messaging
    • Implementing USSD functionality for quick access to CRM features
    • Ensuring data security and privacy for customer information
