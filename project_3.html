    • What Problem Does It Solve?

    Chamas (Savings Groups) are common in many communities, but managing them manually is time consuming and error prone. This project aimed to create a digital system that helps Chama members manage savings, track contributions, and handle basic e-commerce transactions.

    My Approach

    I focused on building a simple yet effective interface for Chama members to:

    • Track their savings contributions
    • View transaction history and balances
    • Manage group activities and payments
    • Handle basic e-commerce transactions within the group context

    Key Lessons Learned

    This project reinforced the importance of understanding user needs and designing interfaces that are intuitive for non-technical users. I also learned about the challenges of integrating financial features and ensuring data security in a simple application.
